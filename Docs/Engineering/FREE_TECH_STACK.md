# Free and Built-in Technology Stack

## Enabled in the project descriptor

- Enhanced Input — keyboard, mouse, controller and rebinding foundation.
- Gameplay Ability System, Gameplay Tags, Gameplay Tasks — abilities, weapons, cooldowns and status effects.
- Niagara — modern VFX, weapon effects and portals.
- Common UI and Common Input — scalable HUD, menus and controller support.
- StateTree — data-driven NPC state logic.
- PCG — procedural environment dressing and repeatable level tools.
- AI Module and Navigation System — bots, navigation and encounter logic.
- Modeling Tools Editor Mode — greyboxing and rapid blockout without external paid tools.

## Built into Unreal; no external install required

- MetaSounds and Quartz for adaptive audio and timing.
- Dialogue Waves, String Tables and the Localization Dashboard for the seven target languages.
- World Partition, Data Layers and One File Per Actor for large environments.
- Control Rig and Sequencer for animation and cinematic prototyping.

## Recommended free external sources

- Lyra Starter Game: architecture reference and optional multiplayer patterns. Do not copy project content without checking its license and requirements.
- Fab free assets: acquire individually, record license metadata, and keep an asset register before shipping.
- Epic Online Services: free service SDK and backend option, but production use requires an EOS product configuration and credentials.

## Deliberately not added yet

- FMOD/Wwise: unnecessary at this stage because MetaSounds covers the prototype.
- Large Fab packs: not downloaded automatically; they can consume significant disk space and have asset-specific license terms.
- Third-party AI generation plugins: use external generation tools for concepts, then review and optimize assets manually.
