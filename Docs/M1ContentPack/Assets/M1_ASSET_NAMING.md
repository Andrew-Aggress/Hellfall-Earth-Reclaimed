# M1 Asset Naming

## Unreal asset prefixes

```text
BP_      Blueprint Actor or Component
W_       Widget
DA_      Data Asset
DT_      Data Table
MI_      Material Instance
M_       Master Material
SM_      Static Mesh
SK_      Skeletal Mesh
T_       Texture
NS_      Niagara System
S_       Sound Wave
SC_      Sound Cue
VO_      Voice line
ST_      String Table
L_       Level / Map
IA_      Input Action
IMC_     Input Mapping Context
```
