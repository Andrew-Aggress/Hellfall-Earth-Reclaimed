## Level design rules

- Every combat arena has two escape routes.
- Every major objective has a visible landmark.
- Secrets are optional and never required for the critical path.
- Elevation must create tactical choices, not navigation confusion.
- Player spawn locations must never face an immediate unavoidable attack.
- Doors and switches require readable visual language.
- Arena completion must be communicated by sound, lighting, and HUD state.
