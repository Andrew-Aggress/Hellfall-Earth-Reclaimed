# M1 — Greybox Combat Slice

## Definition of done

- Fast first-person movement with jump, air control, and slide.
- Enhanced Input for movement, look, jump, slide, fire, restart, quicksave, and quickload.
- One data-driven weapon: Valkyrie Arc-Carbine.
- One original enemy: Razor-Stalker.
- Health, armor, ammo, damage, death, and restart.
- Greybox arena with two routes, cover, elevation, door, secret, pickups, and NavMesh.
- Minimal HUD for health, armor, ammo, crosshair, and death state.
- Localization-ready UI using `FText` and String Tables.
- Save/load foundation for player state and transform.
- Performance target: stable 120 FPS in the packaged greybox build.

## Supported languages

`en`, `uk`, `ru`, `de`, `pl`, `fr`, `it`
