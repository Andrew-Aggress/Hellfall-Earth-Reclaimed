## Usage rules

- Treat these as visual direction, not final game assets.
- Preserve the color language: cyan energy, magenta dimensional effects, toxic yellow industrial markings, graphite metal, rust and dark concrete.
- Keep gameplay readability above decorative detail.
- Create final production assets separately and verify their commercial usage rights.
