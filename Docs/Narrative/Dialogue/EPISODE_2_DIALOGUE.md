# Episode 2 — Dialogue Pack

## Arrival at Blackwood Armory

**MARA:** Defense belt entrance ahead.

**ROOK:** I expected guns.

**MARA:** There are guns.

**ROOK:** I expected fewer factories.

**SOREN:** The factories were the point.

## The Forge reveal

**SOREN:** That frame is not a weapon.

**ROOK:** It is larger than a weapon.

**SOREN:** It is a door.

**MARA:** A door between realities.

**ROOK:** Then we close it before someone walks through.

## The Architect encounter

**ARCHITECT:** You navigate the structure as if it belongs to you.

**ROOK:** It was built by humans.

**ARCHITECT:** Humans built the raw material. I built the purpose.

**ROOK:** You mistake use for ownership.

## Tether launch

**MARA:** Orbital station response is active.

**ROOK:** Friendly?

**MARA:** It is broadcasting an Aegis identification code.

**SOREN:** That code was retired before the invasion.

**ROOK:** Then someone has been waiting.

## Episode 2 closing line

**MARA:** Rook, when we reach orbit, do not trust the station.

**ROOK:** I do not trust buildings.

**MARA:** This one remembers who built it.
